# 📘 کتابچه راهنمای توسعه‌دهندگان EduCore

به کتابچه راهنمای توسعه‌دهندگان **EduCore** خوش آمدید.

هدف از این کتابچه، مستندسازی قوانین، ساختار و استانداردهای پروژه است تا تمام اعضای تیم با یک روش یکسان پروژه را توسعه دهند.

این کتابچه همزمان با پیشرفت پروژه تکمیل می‌شود و هر فصل مربوط به بخشی از توسعه EduCore خواهد بود.

این مستند برای اعضای تیم نوشته شده است و شامل موارد زیر خواهد بود:

- آشنایی با ساختار پروژه
- قوانین کار تیمی
- نحوه کار با Git و GitHub
- معماری Backend
- معماری Frontend
- طراحی پایگاه داده
- استانداردهای طراحی API
- نحوه توسعه Featureهای جدید
- قوانین کدنویسی
- فرآیند انتشار نسخه‌های جدید
